When a later experiment contradicts an earlier conclusion in a homework notebook, leave the earlier section as written (with its guess) and write the later section as "可是我還是覺得怪怪的，所以…", ending with the earlier guess being overturned. Do not go back and replace the earlier text with the corrected explanation. Write in first person, the way a student narrates what they tried.

**Why:** DS HW3 A4 (2026-11-18): I had silently rewritten the "JPEG noise" guess after a third image disproved it. The user said 「寫得更像是人，前面結論不用改，後面說可是我還是覺得怪怪的所以…推翻了之前的結論」.

**How to apply:** each extra test gets a stated reason for running it ("想測的原因"), then the result. Numbers still have to be verified. Related: [[document-readability]], [[writing-style]].
