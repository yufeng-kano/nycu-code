## TA template

Paths in this section are relative to `notebook/`. Three-scale YOLOv3. `src/config.py`: backbone `darknet53.c2ns_in1k` from timm (`features_only`, strides 32/16/8), input 416, the nine original YOLOv3 anchors normalised by 416. `src/dataset.py`: reads the txt lists, keeps a COCO-format dict for evaluation, resizes every image to a square (no letterbox), hflip only when `train=True`, and encodes targets as three `(S, S, 3, 25)` tensors `[tx, ty, w, h, obj, one-hot]`; anchors are ranked by size IoU and the first free slot among the nine is taken; grid cells whose centre lies inside a crowd box get `obj = -1` (ignored). `src/evaluate.py`: pycocotools AP in original coordinates, conf 0.01. `src/predict_test.py`: writes `result.csv` with class-wise NMS 0.4, conf 0.01, 100 boxes max. The notebook trains 50 epochs, batch 16, AdamW lr 1e-4, wd 5e-4, cosine to 1e-6, AMP, selects the checkpoint by val loss and prints COCO AP every 5 epochs.

## Main-line code (notebook/src)

- `det_data.py`: `DetectionDataset` (subclass of the template dataset, `encode_target=False`) with letterbox, YOLOv5-style mosaic on a 2s canvas + random affine, HSV, hflip; targets are `(n, 5)` `[class, x1, y1, x2, y2]` pixels on the network input, `detection_collate` adds a batch index column; `boxes_to_original` undoes the letterbox. Crowd boxes are dropped for training. `cv2.setNumThreads(0)`.
- `detector.py`: `Detector` = `TimmBackbone` (features_only, strides 8/16/32) -> `PAFPN` (C2f-style CSP blocks, width 256, depth 2) -> `DecoupledHead` (cls + 4 * reg_max DFL logits per level). `forward` returns flattened cls/reg logits with anchor points and strides; `inference` decodes, multi-label scores, class-aware NMS (conf 0.001, IoU 0.65, 100 boxes).
- `det_loss.py`: `TaskAlignedAssigner` (top-k 10, alpha 0.5, beta 6, batched over padded GT) and `DetectionLoss` (BCE vs alignment scores, CIoU, DFL; 7.5 / 0.5 / 1.5, normalised by the target-score sum).
- `det_eval.py`: `evaluate_detector` (pycocotools through `evaluate.coco_bbox_ap`, optional hflip TTA pooled with NMS) and `write_submission` (Kaggle CSV format).
- `det_train.py` (2026-11-06, defaults updated 2026-11-09): `TrainConfig` (defaults = the 015 recipe: ConvNeXt-B, PAFPN width 384 / depth 3, 800, multi-scale 0.6-1.25, mosaic + copy-paste 0.5 + mixup 0.15, drop path 0.4, gradient checkpointing, batch 12, 40 epochs; `train_on_val` + `holdout` 400 build `trainval.txt` / `holdout.txt` in the checkpoint dir through `split_lists`, `select="last"` keeps the last epoch's EMA weights instead of the best-holdout ones) and `train_detector(cfg, data_root, checkpoint_dir, run_name, device, log, smoke)` returning the best-AP EMA model and the history; the same loop as the `scripts/train` scripts, for the notebook. CPU smoke test passed.
- `scripts/tools/predict.py --run <name> [--image-size N] [--tta-scales 0.75 1.1] [--no-tta] [--no-csv]`: val AP (plain and TTA) from a run's best checkpoint and its Kaggle CSV; the model config comes from `<run>-last.pt`.
- Pitfall found 2026-11-05: `torch.backends.cudnn.benchmark = True` with batch-level multi-scale stalls the run for minutes per new input size (ConvNeXt depthwise convs); keep it off in multi-scale runs. One step at 640 / batch 16 is about 0.4 s on the shared 3090 Ti, 11.6 GB peak.
